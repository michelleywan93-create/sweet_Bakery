# Bakery Inventory Management

A responsive static Bakery Inventory Management dashboard built with HTML, CSS and JavaScript.

## Features

- Dashboard statistics
- Inventory product table
- Search and category filters
- Low-stock detection
- Add / edit / delete inventory items
- Supplier page
- Reports summary
- LocalStorage data persistence
- Responsive mobile layout
- GitHub Pages compatible

## Files

- `index.html`
- `style.css`
- `script.js`

## Run locally

Open `index.html` in your browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)`.
7. Save.
8. GitHub will provide the public website link.

No database or server is required for this version. Inventory changes are stored in the browser using `localStorage`.
